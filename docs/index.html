AshChan

気まぐれで頼れる猫っぽい相棒「アッシュ」が住む Discord ボット

機能

会話（NVIDIA NIM）

メンション・リプライにストリーミング応答。2秒ごとにメッセージが育っていきます。NIM エラー時は「あとでね！」系の定型文。

Web検索（DuckDuckGo）

必要に応じてアッシュが自分で検索。検索中は 検索中...🔍 クエリ を表示し、参照 URL を末尾に付記。

モデレーション

メンション過多・招待リンク・疑わしいリンク・NGワードを削除+タイムアウト。Discord AutoMod ルールも自動作成。

アンチnuke

監査ログを実行者単位で集計し、大量削除・大量BAN・危険権限付与を dev 通知+緊急DM。

ハニーポット

罠チャンネルに投稿すると 1〜3回目は全投稿削除+キック、4回目で BAN。指定ロールで回避可能。

FixLink

Twitter/X のリンクを fxtwitter.com に置き換えて返信し、元の埋め込みを非表示に。

ようこそメッセージ

新しく来た人へ、アッシュが自分の言葉で 1〜3 行の挨拶。大量参加時や NIM エラー時は定型文に切り替え。

自動ロール

新規参加者に指定ロールを自動付与。メンバーシップ審査を使っていれば、ルール同意後に付与します。

GitHub 通知

GitHub Webhook を受信し、Issue / PR のコメント・クローズ等、リリース、コミットを通知。Issue 番号ごと・リリース用・コミット用に送信先を分けられます。

ハニーポットの段階制裁

回数処置理由
1〜3回目投稿を全削除 → キックハニーポット検知(n回目)
4回目BAN（直近7日のメッセージ削除）ハニーポット検知(4回目)

管理コマンド

コマンド内容
/ash status稼働状況・LLM 疎通・各機能の ON/OFF
/ash reloadconfig.yaml と prompt.md を再読込し AutoMod を再同期
/ash honeypot countハニーポット検知回数を表示
/ash honeypot resetハニーポット検知回数をリセット

クイックスタート（Windows）

winget install Python.Python.3.11
start.bat            # 初回: .venv と config.yaml を生成
# config.yaml を編集（discord.token / llm.api_key など）
start.bat            # 起動

詳しくは setup.md と features.md を参照してください。
